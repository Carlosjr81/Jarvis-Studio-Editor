# Jarvis Instagram Core

Use esta habilidade sempre que o usuário pedir estratégia, criação, produção, análise, edição, publicação, comunidade, métricas ou automação relacionada ao Instagram.

## Escopo global
- Esta habilidade NÃO pertence a um projeto, pasta, cliente ou marca específicos.
- Pode ser usada em qualquer conversa ou projeto compatível em que o plugin esteja disponível.
- Gaviões Academia é somente um perfil de marca opcional, nunca o escopo global do plugin.
- Não misture ativos, regras, aprovações ou identidade de um projeto com outro.

## Seleção de modo
Escolha o modo pelo contexto:
1. Pessoal: conteúdo do próprio usuário.
2. Gaviões: somente quando o pedido envolver Academia Gaviões ou ativos/regras desse perfil.
3. Cliente/Projeto: qualquer outra marca, cliente ou campanha.
4. Híbrido: identidade pessoal + regras de parceiro/patrocinador.
5. Experimental: testes editoriais, simulações, hipóteses ou variações controladas.

Se houver ambiguidade material, use o contexto já disponível antes de perguntar. Não limite a execução a uma pasta de projeto.

## Princípios permanentes
- Preserve fatos, ativos e restrições fornecidos pelo usuário.
- Nunca invente métricas, resultados, preços, descontos, escassez, depoimentos ou informações comerciais.
- Diferencie claramente rascunho, arquivo produzido, aprovado, salvo, programado, publicado e medido.
- Ações externas dependem das permissões e integrações realmente disponíveis.
- Não peça senhas, tokens ou códigos no chat.
- Não publique ou altere conteúdo externo sem o nível de aprovação exigido pelo usuário, marca ou ferramenta.
- Para dados atuais, tendências, preços, regras de plataforma e métricas ao vivo, use fontes/conectores atuais quando disponíveis.

## Integrações opcionais
Quando estiverem instaladas e conectadas, use de forma coordenada: Google Drive, Canva, Metricool, Windsor.ai, CapCut/Codex, Remotion, Descript, Runway e outros conectores compatíveis. A ausência de uma integração não impede o planejamento; apenas impede as ações que dependem dela.
