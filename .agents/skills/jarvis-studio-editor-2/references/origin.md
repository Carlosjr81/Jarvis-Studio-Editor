# Origem e limites

O histórico registra criação da habilidade Studio Editor e uso do editor em 04–05/10/2026, com timeline/camadas/legendas e integração Spotify. A versão 2 recupera a entrada de operação ausente no catálogo.

Fonte de código: Carlosjr81/Jarvis-Studio-Editor, README e jarvis-studio-source.zip. O README documenta OpenCut Classic e distingue software compartilhado de projetos/mídias privados. O Site existente foi confirmado ativo durante a reconstrução; isso não homologa cada recurso em cada aparelho.

Não substituir o aplicativo por uma tela de instruções. A habilidade coordena a ferramenta existente e execução local; não é uma nova implementação do editor.
